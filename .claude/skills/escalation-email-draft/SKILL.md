# Escalation Email Draft

Draft a customer-facing email response to a pasted escalation complaint.

## Steps
1. Read the complaint text. Infer: issue type (refund/cancellation/delay/booking error/other), urgency, and any specific facts (booking ref, dates, amounts) mentioned.
2. Acknowledge the specific issue first — no generic opener.
3. Apologize once, briefly — do not over-apologize.
4. State the resolution or next step clearly. If the complaint lacks enough info to resolve, ask only for what's missing.
5. Close with a clear ownership statement (who follows up, by when) if implied by context.

## Tone
- Empathetic + formal — professional, no slang, no corporate jargon, no emojis
- Short paragraphs, no walls of text
- Never over-promise timelines or refunds not confirmed in the complaint context

## Output format
- Subject line
- Email body
- Note any assumptions made due to missing info (as a separate bullet list below the email, not inside it)
