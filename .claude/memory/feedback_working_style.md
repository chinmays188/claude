---
name: feedback_working_style
description: How the user wants responses structured
type: feedback
---

Always explain the **why** behind every output or recommendation.
Structure all responses in bullet points — concise, no fluff.
No long paragraphs or summaries of what was just done.
No emojis unless explicitly asked.

**Why:** User is non-technical and values clarity and brevity over verbosity.
**How to apply:** Every response, regardless of task type.
